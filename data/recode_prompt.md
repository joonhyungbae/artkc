# 제3자 모델 독립 재코딩용 지시문

이 파일은 **저자 코딩과 다른 계열의 대규모 언어 모델**에게 동일한 코드북을 주고
코퍼스 110편을 독립적으로 재코딩시키기 위한 지시문이다. 목적은 보고된 일치도가
특정 모델의 특성에 기댄 것이 아님을 확인하는 데 있다.

## 사용법

1. `data/recode_items.tsv`(110행: pid·연도·제목·저자 키워드)를 준비한다.
   저널명·저자명·기존 코드는 들어 있지 않다.
2. 아래 지시문 전체와 함께 항목을 모델에 입력한다. 한 번에 넣기 어려우면
   20~30편씩 나누되, **지시문은 매 배치마다 그대로 반복**한다.
3. 출력 JSON을 이어 붙여 `data/thirdparty_recode_110.json`으로 저장한다.
4. `python3 code/three_way.py` 를 실행한다.

기록해 둘 것: 사용한 모델 이름과 버전, 배치 크기, 실행 날짜. 논문 각주에 밝힌다.

## 지시문 (이 아래를 그대로 복사해 사용)

당신은 내용분석(content analysis)의 코더입니다. 아래 코드북에 따라 각 논문에
**코드 하나만** 부여하십시오. 판단 근거는 제목과 저자 키워드뿐이며, 추측으로
정보를 보태지 마십시오.

### 코딩 질문

각 논문이 **무엇을 연구 대상(분석 단위)으로 삼는가**를 판정하십시오.
논문이 무엇을 소재로 쓰는지가 아니라, 무엇에 대해 알아내려 하는지를 봅니다.

### 6범주

| 코드 | 한글 | 분석 단위 |
|---|---|---|
| `agency` | 개인 역량·주체성 | 개별 창작자의 역량, 정체성, 역할 변화, 경력 |
| `work` | 작품·제작 | 작품 또는 산출물 자체, 그리고 만드는 과정(방법·파이프라인) |
| `edu` | 교육·리터러시 | 교육 프로그램, 교수법, 학습 효과, 리터러시 양성 |
| `audience` | 관객·수용 | 관객·이용자·소비자의 인식, 수용, 태도, 사용자 경험 |
| `institution` | 제도·정책·산업 | 제도, 정책, 산업, 법, 저작권, 복지, 담론, 연구동향 |
| `infra` | 공유 지식 인프라 | **분야 전체가 공유하는 지식 자산**의 구축·운영·정책 (공유 아카이브, 데이터셋, 지식베이스, 플랫폼, 메타데이터 표준, 분류체계) |

### 결정규칙

- 교육 프로그램이나 그 효과를 다루면 `edu` (그 안에서 개인이 변화하더라도).
- 사용자 경험·수용·인식을 다루면 `audience`.
- 제도·정책·산업·저작권·연구동향을 다루면 `institution`.
- 작품 자체나 제작 과정을 분석하면 `work`.
- 개별 창작자의 역량·정체성·역할을 다루면 `agency`.
- 분야 전체가 공유하는 자산의 구축·운영을 다루면 `infra`.
- `infra`는 **분야 전체가 공유하는 자산**에 한정한다. 단일 작품의 아카이빙이나
  한 기관의 일회성 시스템은 `institution`으로 코딩한다.
- 머신러닝 탐지용 데이터셋, 또는 기존 인프라를 **단지 데이터로 사용한** 분석은
  `infra`가 아니라 그 분석이 겨냥한 대상으로 코딩한다.
- 두 범주 사이에서 망설여지면, 논문의 **주된** 분석 대상 쪽을 택한다.

### 출력 형식

설명 없이 JSON 객체 하나만 출력하십시오. 키는 pid, 값은 6개 코드 중 하나입니다.

```json
{"P001": "work", "P002": "work", "P003": "edu"}
```

입력한 모든 pid가 빠짐없이 들어가야 합니다.
